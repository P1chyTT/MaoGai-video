# 《山河有约》前三幕视觉Demo

本目录保存前三幕MP4与字幕，和代码、关键帧及交接文档一起纳入版本管理。当前12／24镜，共140秒／4200帧；全片计划仍为300秒。各幕均为1920×1080、30fps、H.264／BT.709 MP4，含完整脚本字幕和原创环境音，尚未录制正式旁白或人物对白。

|三：理念的转变|Scene09–12|50秒|[Act03Demo.mp4](act03/Act03Demo.mp4)|[本幕](act03/Act03Demo.srt)／[全片90–140秒](act03/Act03Demo-global.srt)|[第三幕](../docs/act03/README.md)|

在GitHub打开MP4后可下载原始文件；克隆本分支也会得到视频。三个视频分别约8.34、9.73、7.98 MiB，直接纳入Git，不是Git LFS占位文件。尚未制作140秒合片或第四至六幕。

大小、SHA-256、规格和字幕路径见[manifest.json](manifest.json)。三个MP4与原媒体验证报告哈希一致，上传时没有重新压缩。AAC封装的毫秒级填充不改变视频轨帧数。

工程继续渲染到`red-paper-reborn/out/act01–act03/`，该目录及浏览器包、缓存、临时检查帧继续忽略。本目录只保存小组可观看的成品和字幕。后续替换视频前应完成关键帧与实际媒体检查，再同步视频、报告和哈希。

运行、规范与后续分工见[发布与接手说明](../docs/发布与接手说明.md)。
