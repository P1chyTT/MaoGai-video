## 开始时的工程与连续性

在原有React、TypeScript、Remotion 4.0.537工程中继续开发，没有重建、迁移或升级依赖。开始时主分支包含前三幕和第四幕备选版；队友第四、第五幕分别在 `act04`／PR #1、`act05`／PR #2。第五幕实际MP4已核对：40秒、1200帧、1080p／30fps、无音轨；抽查回老屋、学剪纸及认错画面。它的新增提交只有视频，没有Scene17–20源码。

本幕从同一木桌的剪纸细节开始，不重演道歉；2秒后回到原老屋，表现小林将手机对准手工过程。之后进入市集体验、共同展示和画卷。没有合并队友PR或改写第五幕。原稿“04:10”不是本工程中的实际起始时间。

若顺接现有36＋55＋60＋50＋40＋20秒六幕视频，参考长度为261秒／4分21秒、7830帧；此数值不是已导出的总片，也不是配音定稿。第四幕正式采用哪个版本仍由团队审片确认。

## 实际美术与素材

继续使用STYLE_GUIDE中的六色：米黄 `#F2E5CB`、深红 `#A52A2C`、青绿 `#246166`、金色 `#C79540`、墨褐 `#2D1E1B`、木棕 `#705037`。阴影和宣纸纹理沿用共享舞台；没有新增照片、3D、AI图像／视频或外部付费接口。

- 奶奶、小林和青年使用原始PNG，原文件字节不变。青年首次作为参与体验的主要角色使用；保留米白镂空上衣、青绿裤、侧脸和铆钉。
- 奶奶特写手臂来自原PNG裁切，从画面上缘进入；剪刀独立开合。没有用整张PNG拉伸伪造手指握剪刀或完整手部骨骼。
- 小林复用头部／前臂分层与 `phoneGrip()`，手机镜头内是桌面同一凤凰，不显示商业数据或夸张宣传封面。
- 市集青年是原图等比轻摆和窗花抬升，并非新增完整骨骼；奶奶坐姿下缘由桌面遮挡。没有夸张嘴型。
- 新剪纸是对称双凤、花卉、祥云与卷草围合的完整构图。城市屋宇和对读青年由同一红色实体与真实负形蒙版形成，主体与边缘藤脉相连；现代部分使用裁切逐步显出，不拆成漂浮图标。
- 最终画卷用青绿远、中、近山，金色祥云和曲水、红色连枝与双凤、木构城楼串联。左侧小群像学习剪纸，右侧复用原奶奶和小林PNG展示窗花；其他侧面人影采用约六头身的简洁皮影轮廓、金色关节和衣纹。

Scene23最后作品坐标固定为 `(480,250)`、960×576；Scene24首帧相同，旧人物与底景在0–0.8秒淡出，作品再缩至 `(660,300)`、600×360。画卷区域裁切于x77–1843、y202–902；字幕带保留底部90px。图形和最终主题在局部210帧后全部停止，没有黑场片尾。

## 字幕与声音的重要限制

原文完整保留在JSON中，不使用图片文字。底部沿用36px宋／仿宋、字距3px、墨褐描边与90px宣纸带；主题沿用29px共享条，最终长主题使用34px、宽1380px的同材质金线条。字幕位于人物和道具上层。

20秒内的四段原文较长，尤其Scene21、23、24，**当前字幕时序仅作为规定20秒的无声视觉版，不能视为自然语速配音方案**。没有相应本地录音，未调用语音生成接口，也未加速配音凑时长。核验JSON列出各段每秒中文字数及密度警告，`voiceover_timing_approved=false`。

正式录音前应由团队确认延长该幕／调整全片节奏的方案；不直接把长文挤在最后一秒，不在本次未经确认改变规定600帧。正式配音到位后重新校准字幕和镜头停留。原分支中的一、二幕音频不属于第六幕旁白，不能挪用。

## 运行与验收范围

在工程目录运行：

```sh
npm install
npm run dev
npm run lint
npm run keyframes:act06
npm run render:act06
python scripts/verify-act06.py
```

Studio选择 `Act06Demo` 或 `Act06-Scenes` 下的Scene21–24。渲染输出 `out/Act06Demo.mp4`；`out/act06/keyframes/`共24张，12张首／中／末和12张动作帧；验证生成两张总览和 `verification.json`。Python辅助检查需要Pillow，非Windows系统需要ffmpeg／ffprobe，正常Studio／MP4渲染无需Python。

主帧：`0/60/119`、`120/165/209`、`210/285/359`、`360/480/599`。附加：`30/90/150/195/240/300/390/420/450/510/540/570`。最后570与599帧进行源图逐像素比较，验证7–8秒稳定停留。人工查看了纸手接触、手机屏幕、青年展示、双凤镂空、23→24交接和最终主题。

自动检查负责导出规格、600帧完整解码、黑／白候选帧、准确台词与主题、字幕范围、三位人物源素材，以及最终停留。艺术评价、实体剪纸是否可手工完整裁出、自然配音和整片混音仍需团队审片，不能据技术通过声称最终全片验收完成。本次没有重新导出前五幕，也没有声称做了全部旧镜头逐像素回归。

本次实际核验结果：`status=passed`（技术范围），20.000秒、600帧、7,401,448字节、H.264／yuv420p；SHA-256为 `ce928f85843b74dddab1fbcde66469fb9ff1d1565bd0ca8a076d1bccf25457db`。奶奶、小林、青年原始文件哈希一致，末秒两代表源帧完全相同，文字密度警告保留。ESLint、TypeScript通过；`check:portable`在临时包去掉可选仿宋后，用分发思源宋体成功渲染第六幕165／285／599帧及前几幕代表帧，不改动源字体。
