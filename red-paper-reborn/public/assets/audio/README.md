# audio

`act01-foley.wav`：第一幕原创程序合成环境音，40秒、48kHz、16bit双声道PCM；没有人物配音，也没有下载音效或商业音乐。

来源为项目内 `scripts/create-act01-foley.py`，固定随机种子20261031，仅Python标准库可再生成。含轻纸响、远处机械低鸣、车轮、关窗、鸟鸣与四个原创拨弦音；无TTS或付费API。当前原始峰值约−19.4dBFS，场景音量0.7。

老周、小禾真人录音、最终音乐与混音尚待制作。录音窗口、SRT与源文件说明见 [第一幕交接](../../../../docs/act01/README.md)。不使用旧项目语音作为新片配音。

## 第二幕

`act02-foley.wav`：第二幕原创程序合成环境音，50秒、48kHz、16bit双声道PCM；没有人物配音、TTS或下载采样。来源为`scripts/create-act02-foley.py`，固定种子20261101。包括机器逐渐停止、工具包落桌、轻脚步、两个低弦音、溪流、铲土和木牌声，结尾保留风声。源音轨峰值约−21.18dBFS，场景音量0.8。录音窗口和两种时间轴SRT见[第二幕交接](../../../../docs/act02/README.md)。

## 第三幕

`act03-foley.wav`：50秒、48kHz、16bit双声道PCM原创程序合成音轨。来源为`scripts/create-act03-foley.py`，固定种子20261102；含纸、笔、杯响、溪水、土与鸟鸣，以及少量原创低音和木管音色。源峰值约−21.25dBFS，场景音量0.8。没有TTS、人物模仿、历史录音、下载采样或商业音乐。配音窗口与原文见[第三幕交接](../../../../docs/act03/README.md)，真人旁白、小禾录音和最终混音仍待制作。
