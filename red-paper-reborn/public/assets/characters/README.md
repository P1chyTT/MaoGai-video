## 后续制作必须遵守

1. 所有镜头先查此库及正式 Word；禁止为了某镜重新设计小禾或老周，禁止使用旧项目人物兜底。
2. 原始文件不可覆盖、裁切、去背景、改色、拼接或风格迁移。图中金属铆钉只是画面内容，不代表已完成骨骼绑定。
3. 当前版本为人物视觉设定模板，正式骨骼动画使用前可能需要进一步分层。后续图层在 `xiaohe/`、`laozhou/`、`crowd/` 等既有目录另命名、记录来源和修改，不复制出第二套原始素材库。
4. 正式脚本中的小禾使用手机／帆布包，而模板持相机／棕色双肩包；保留原件，后续制作脚本道具与手势衍生件。老周中年版、各职业动作与儿童素材尚缺。
5. 工程 public 根是 `red-paper-reborn/public/`；参考图可用 `staticFile('assets/characters/xiaohe.png')` 等引用。含姓名文字的完整图不能直接镜像为反向角色，不能直接当透明人物放入场景表演。
