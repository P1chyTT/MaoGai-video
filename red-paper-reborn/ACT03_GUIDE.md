更新日期：2026-10-24。

**当前状态：视觉、代码和60秒MP4已完成；1800帧全解码、字幕和三位人物素材校验通过。**

第三幕为独立60秒视觉 Demo：1920×1080、30fps、1800帧。延续前两幕的彩色皮影、宣纸幕布、同一老屋与右上暖光；人物使用原始奶奶、小林和商家PNG。没有本地声音素材，目前为静音视觉版本；正式配音后再校准字幕时序。

## 预览、导出与帧数

在 `red-paper-reborn` 工程目录运行：

```sh
npm run dev
npm run keyframes:act03
npm run render:act03
python scripts/verify-act03.py
```

Studio选择 `Act03Demo` 连续预览，或选择独立 `Scene08`–`Scene12`。预览地址以终端为准，通常为3000端口；第三幕渲染器使用3106端口。

`Root.tsx` 和 `package.json` 仅增加第三幕注册及命令；依赖版本未变更。继续使用 `ShadowStage`、`OldHouseStage`、`PuppetCharacter`、`ScissorAnimation`、`PhoenixMotif`、`Dialogue`、第二幕 `ThemeCaption`、字体加载与统一 `styleTokens`。

共享接口的新增项保持旧默认行为：

- `OldHouseStage`：`heldTools`、`restingScissors`、`tablePaper` 默认均为 `true`，分别控制手中剪刀／红纸组、原桌面剪刀和原桌面整张红纸；`behindTable` 插入桌前沿之后的角色层，`puppetForearmAngle` 为可选前臂角度。
- `PuppetCharacter`：只有传入 `forearmAngle` 才启用新前臂裁切，角度限制在0–22°；第三幕Scene12使用此动作，前两幕未传参数的路径不变。
- `XiaolinPuppet`：新增可选 `pose`、`x`、`y`、`width`，支持第三幕定姿和站位，原默认姿态与位置不变；第三幕传自定义姿态并继续使用合法的旧 `shot` 类型。
- `MerchantPuppet`：身体、头部和前臂分层，保留原PNG纹理与轮廓；关节输入限制在±3°，没有重新绘制人物或制作完整全身骨骼。

## 已采用的构图与动作

Scene08仍在老屋局部机位。电脑桌用同一木棕、墨褐轮廓和金色细节构成，作为前景遮住原桌；小林位于 `(1110,210)`、宽610px，桌沿裁去腿部形成坐姿。镜头末段推至1.12倍。

Scene09、Scene10商家基准为 `(1280,145)`、宽530px；Scene10最后3秒逐步退至 `(1370,180)`、宽480px，Scene11、Scene12保持该位置。小林在Scene11向 `(1070,210)`、宽480px的位置靠近，另有12px侧移动作；手机用相同身体与手臂变换跟随手掌。Scene09末段镜头至1.09倍，Scene12逐渐推至1.115倍，人物与世界道具共同经过镜头变换。小林的纵坐标已通过最后推近时的主题字幕安全区检查。

凤凰放在老屋桌面 `(988,718)`，显示尺寸358×77px、旋转−4°，保持一张扁平连贯红纸。镂空区域透出木纹，没有以实色补洞，也没有粒子化。价章位于 `(1052,815)`、缩放0.62；Scene10逐渐减弱商业强调，Scene12末尾进一步降低价章存在感，把视觉中心留给奶奶和凤凰。

Scene12奶奶前臂围绕原铆钉旋转，原图肘部坐标为 `(632,525)`；等比显示坐标为 `(413.515625,343.505859375)`。剪刀沿相同旋转关系下落，最终接到桌面 `(979,755)`。本幕关闭共享舞台原手中组、原桌面剪刀与整张红纸，由第三幕显式管理剪刀和凤凰，避免重复道具。动作是原图局部分层与独立道具配合，没有拉伸整张人物或增加夸张口型。

所有运动以 `useCurrentFrame()`、`tween()` 和固定参数计算。暖光、纸纹、阴影与六色体系延续前两幕；商业内容保持纸片／皮影道具语言。对白复用底部 `Dialogue`，主题复用 `ThemeCaption`，保留统一字体、安全区和样式。
