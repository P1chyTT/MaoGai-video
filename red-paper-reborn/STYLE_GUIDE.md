# 《红纸新生》第一幕美术与动画规范

第六幕（2026-10-25）沿用本文六色、人物源图、宣纸、阴影和字幕，不修改全局规范。市集、双凤／城市青年连枝剪纸、青绿画卷的实际布局与接口见 [ACT06_GUIDE.md](ACT06_GUIDE.md)。片尾原图两代人保留原色，其他小群像采用成人侧面比例、金色铆钉与衣纹；最后1秒所有图形和文字停止。20秒静音视觉版不等同于自然配音时序已定稿。

第三幕（2026-10-24）继续采用本文六色、宣纸、老屋和字幕标准。新增商业纸片道具、电脑桌与原图前臂动作的实际参数见 [ACT03_GUIDE.md](ACT03_GUIDE.md)；不改变前两幕默认输出。

基准：1920×1080、30 fps、36 秒、1080 帧。入口 `src/index.ts`，主合成 `Act01Demo`。

## 舞台、材质与空间

- 二维切片结构：后墙／窗外远景，人物／桌面中景，左侧卷草前景，固定幕框。布景采用 SVG 平面轮廓。
- 窗框世界坐标 `(1244,205)`，尺寸 `444×436`；桌面后沿 `(574,727)` 至 `(1599,727)`，前沿 y=807。后续房间镜头复用 `OldHouseStage`。
- 光始终从右上窗户斜向左下。低透明度暖色光片轻微移动；纸尘仅九枚微小椭圆，不使用光粒子。
- 宣纸静态纹理 `paper-grain.svg` 以固定种子生成，叠加透明度 7.5%。木纹用细长弧线，不逐帧抖动。
- 木构主轮廓 3–5 px，雕花和金线 1–2 px。桌体阴影 `(0,8)`、模糊 5 px、墨褐 16%；人物 `(5,7)`、模糊 3 px、18%；纸张 `(3,5)`、模糊 2 px、26%。
- 凤凰是代码手绘的连枝剪纸：外圈、长颈侧面、冠羽、八片扇形翅羽、长尾、三组团花、卷草。`PhoenixSilhouette` 构造实体，`PhoenixHoles` 刻出负形，不拆成粒子。

## 人物比例与动作

- `grandma.png` 是附件的原字节副本；原附件未修改。四位素材的 SHA-256 在 `public/assets/characters/SOURCES.json`，本幕仅使用奶奶。
- 原图 1024×1536，等比绘制为 670×1005，放在 `(445,205)`。桌沿后可视高度限制为 570 px，形成坐姿遮挡；没有拉伸身体、重画服饰。
- 同一 PNG 的互补 CSS 多边形裁出头与身体；头部显示坐标转轴 `(373,162)`，最大抬头 2.1°。身体轻摆不超过 ±0.24°，不做夸张嘴型。
- 本版没有完整手臂骨骼，用独立剪刀和纸张配合极小姿态变化。后续分层应沿原关节裁切，保留原纹理、铆钉和轮廓。

## 时间与镜头

|镜头|全局帧（含首尾）|时长|实际运动|
|---|---|---|---|
|01|0–239|8 秒|0–30 帧亮幕；30–150 帧推进 1→1.045；135–210 帧纸角抬落|
|02|240–689|15 秒|剪刀每69帧开合；局部120–240帧老人过窗；270–345帧抬头；390–440帧回看纸；末2秒向桌面移近|
|03|690–1079|13 秒|前2.5秒推进；2.5–5秒中线展开；5–6.8秒轮廓遮罩；6.2–9秒镂空遮罩；9–11.5秒轻推3.5%；末段停留|

- 缓动统一为 `Easing.bezier(0.42,0,0.22,1)`，两端 clamp。第一镜倍率不超过 1.045。
- 剪刀69帧周期：0–15帧打开、15–21帧停留、21–33帧合拢，再停顿。局部9–13秒动作幅度逐渐减小。
- 前两镜在相同的1.045倍房间比例处切换；第三镜为同一木桌的二维桌面插入特写，保留同向窗光与木纹规范。
- 主合成使用相邻 `Series.Sequence`，不重叠消耗帧数。三个镜头独立注册，能在 Studio 单独打开。
- 动画仅由帧、fps、固定插值、三角函数驱动。无 CSS animation、计时器或运行时随机数。

## 字幕与声音

仿宋36 px，字距3 px，行高1.35，墨褐字，0.25 px同色描边和1 px米白浅影；底部25 px，独立宣纸字幕带高90 px。字幕与毫秒区间在 `captions.json`，字段采用 Caption 数据结构。尚无配音，当前按阅读节奏排句，后续随录音微调。

已导出样片使用本机仿宋，`fangsong.ttf` 仅作为本地可选文件，不上传仓库。仓库提供 Adobe 思源宋体 `SourceHanSerifSC-Regular.otf` 及其 SIL OFL 许可：新电脑会自动使用这一后备字体，字幕的字面和宽度可能略有区别。若要复刻样片字体，请在具有相应使用许可的电脑上准备 `public/assets/fonts/fangsong.ttf`。本版无声，未发现本地配音或音效，也未调用语音或视频生成 API。

## 组件接口与复用

|组件|参数和职责|
|---|---|
|`ShadowStage`|`children`；宣纸、纹理、固定幕框和暗角|
|`OldHouseStage`|`frame`环境连续时间；`grandmaFrame?`存在时显示奶奶；`scale/shiftX/shiftY`机位；`intro`纸角；`detail`桌面插入；`children`特写道具|
|`PuppetCharacter`|`frame`；原图坐姿裁切、轻摆、抬头|
|`ScissorAnimation`|`frame,x,y,scale,rest`；围绕铆钉开合，rest表示桌上静止|
|`PaperReveal`|镜头局部帧；折叠、展开、轮廓与镂空遮罩|
|`PhoenixMotif`|`id,holes`；静态凤凰，holes控制镂空透明度，id必须唯一|
|`Dialogue`|`captions`；统一字体、安全区和分句|

新镜头先继承房间世界坐标，再添加道具／人物。SVG defs 用 `useId()`，避免预加载镜头之间发生 ID 冲突。人物加载使用 Remotion `Img`；字体通过 `delayRender/continueRender` 等待，保证导出首帧完整。
