# 《山河有约》项目背景与制作规范

更新日期：2026-10-31。课程选题：推进生态文明建设。默认片名：《山河有约》；副标题：从绿水青山到金山银山。

## 制作依据与当前阶段

本项目依据用户提供的[余村故事线视频脚本](视频脚本/推进生态文明建设_余村故事线视频脚本.docx)开展制作。逐镜数据以[shots.json](视频脚本/源码/shots.json)为准，完整对白、画面、动作、声音与转场见Word及[content.py](视频脚本/源码/content.py)。仓库内的脚本源码来自用户确认收录的`.codex-yucun-script`，原目录保留；复制记录见[来源记录.json](视频脚本/来源记录.json)。

目标为六幕24镜、300秒、9000帧的MG动画。当前是新项目基础工程和技术预览阶段，24镜全部待制作。`TechnicalPreview`约定为5秒、150帧，仅用于检查舞台、山水分层、镜头和字幕；它不计入正片时长和制作完成率。

旧《红纸新生》已通过归档分支和标签保留。新项目在`project/shanhe-youyue`分支推进，默认`master`不变。工程继续使用历史目录名`red-paper-reborn/`，目录名称不代表影片主题。旧片人物、分镜、成片和完成状态不作为本片制作成果。

## 主题与人物

故事发生在浙江省湖州市安吉县天荒坪镇余村，以当下返乡与历史回望交织展开。小禾起初想拍家乡“热门”，老周用旧图讲述产业带来收入与污染的矛盾；关停后的生计压力、长期修复和绿色经营推动小禾理解长远发展。她最终记录普通劳动、制作课程中的步行路线和绿色出游提示，与爷爷共同完成拍摄。

核心立意是在保护好生态的前提下转变发展方式，通过适宜产业、认真经营和共同参与，促进生态效益、经济效益、社会效益相统一。生态价值包含多种价值，画面不将山水直接变成货币。

| 角色 | 身份与变化 | 造型及资产要求 |
| --- | --- | --- |
| 老周 | 虚构综合人物；现实约六十多岁，回忆中参与矿山或相关工业生产；沉稳、关心后代，支持孙女接力 | 棕色上衣；现实版与中年版共享侧脸识别特征，工作帽为回忆道具；新造型待设计 |
| 小禾 | 虚构大学生，返乡完成课程拍摄；由追求热度转向记录劳动、理解保护和参与行动 | 绿衣、帆布包、手机、纸质清单；新造型待设计 |
| 村民群像 | 三套复用综合模板，承担劳动、经营和日常生活，不新增有名支线人物 | 以帽子、围裙、工具、背包替换；新模板待设计 |

老周、小禾及家庭故事均不对应真实人物。新角色资产目前缺失，须按本片设定设计；旧片奶奶、小林、商家不用于本片角色。史实与艺术虚构的边界见[史实与参考资料](史实与参考资料.md)。

## 画面与动画规范

采用传统皮影与剪纸语言：宣纸幕布、侧面人物、关节铆钉、平面建筑、SVG分组、遮罩、分层视差及帧驱动关键帧。不使用文生视频服务。可延续通用舞台、纸纹、字幕安全区和动作设计方法，场景与人物按新脚本制作。

| 色彩 | 色值 | 用途 |
| --- | --- | --- |
| 森林绿 | `#315D45` | 近处竹林、植被、主要生态图形 |
| 山水青 | `#6A9B8B` | 中景山体、溪岸、植物层 |
| 天空蓝 | `#A8C9C2` | 远山、天空、清水高光 |
| 大地棕 | `#8A6849` | 旧矿山、土地、工具、老周衣装 |
| 宣纸米黄 | `#F2E5CB` | 底幕、字幕承托、纸质道具 |
| 传统金色 | `#C79540` | 铆钉、山脊细边、机制连接线 |

第一幕以棕土、灰尘和裸露坡面为主；第二幕逐步增加苗木和清理动作；第三幕以宣纸资料卡呈现历史信息；第四幕逐块补入竹林、清水与经营空间；第五、六幕以青绿为主、暖金点缀。环境改善通过坡面、杂物、植被和维护动作表现，避免用全屏换色代替治理过程。

纸纹固定，建议透明度6%—8%；主体描边3—5像素，细纹1—2像素；人物轻影向右下约5像素。照明方向统一，使用局部暖色透光。动画由帧号、固定插值与关键帧驱动；需要随机时固定种子。手臂绕实际关节转动；纸张、手机等道具随手部绑定。单镜推进一般3%—8%。

## 画幅、字幕与声音

- 画幅：1920×1080，16:9，30fps。六幕分别1200、1500、1500、1500、1800、1500帧；逐镜区间见[分镜与制作进度](分镜与制作进度.md)。
- 安全区：左右各120像素、上下各70像素；底部保留约160像素字幕区。
- 对白字幕：建议思源宋体或宋体，40—44像素，两行以内，每行尽量不超过22个汉字，按语义分句。字体文件与使用许可待确认。
- 资料文字：日期和理论主字置于上半部；普通说明不低于28像素；片尾来源可用24—26像素并保证阅读停留。文字保持可编辑。
- 配音：老周温和沉稳，小禾前段轻快、后段认真，旁白客观自然；各角色分轨，镜内对白不重叠。实际录音超窗时优先调整停顿、重录或精简，保持自然语速。
- 片尾：对白在296.5秒前结束，最终主题自294秒完整保留6秒，最后2秒所有图层静止，300秒整结束。不得额外延长黑场。

## 工程与交接

工程位于`red-paper-reborn/`，沿用React 19.2.3、Remotion 4.0.537、TypeScript 5.9.3，本次迁移不升级依赖。素材目录为`red-paper-reborn/public/assets/`，已预留`audio/`、`backgrounds/`、`characters/`、`elements/`、`fonts/`、`motifs/`、`props/`；目录存在不等于资产已完成。

每镜交接应包含：镜号与时长、资产清单、关键帧、字幕数据、声音文件、来源标记及待办。建议以`Scene01`—`Scene24`统一两位数命名，独立制作后按全局起点拼接。正式配音、音乐及音效授权、角色资产、逐镜动画、全片音画验收均待完成。

交付验收检查字体缺字、替换、图层遮挡、道具漂移、字幕阅读、镜间衔接、史实资料卡、来源和末帧停留。脚本估时与技术预览不能代替300秒正式音画验收。
