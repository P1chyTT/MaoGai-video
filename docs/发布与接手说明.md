## 队友启动与检查

```sh
git clone --branch project/shanhe-youyue https://github.com/P1chyTT/MaoGai-video.git
cd MaoGai-video/red-paper-reborn
pnpm install --frozen-lockfile --config.node-linker=hoisted
pnpm run dev
```

Node.js建议22.13+或24。沿用React19.2.3、TypeScript5.9.3、Remotion4.0.537锁定依赖。工程路径`red-paper-reborn/`保留历史命名，内容均为《山河有约》。Studio通常在3000端口，以启动输出为准；选择`Act01Demo`、`Act02Demo`、`Act03Demo`或各独立Scene。localhost预览须先在自己的电脑启动工程。

```sh
pnpm run lint
pnpm run check:project
pnpm run check:portable
pnpm run check:act01
pnpm run check:act02
pnpm run check:act03
pnpm run keyframes:act03
pnpm run render:act03
```

其他幕将最后两条命令的`act03`换成`act01`或`act02`。正式渲染输出`out/actXX/`；旧`render`／`keyframes`与`TechnicalPreview`只是5秒技术检查，不是完整影片。

## 后续必须沿用的规范

1. 先读[正式Word](视频脚本/推进生态文明建设_余村故事线视频脚本.docx)、[人物设定](人物设定与视觉规范.md)、[史实与参考资料](史实与参考资料.md)和对应幕交接，不自行改变对白、人物关系、历史事件或来源编号。
2. 原始PNG在`public/assets/characters/`，没有被覆盖或去背景。当前SVG衍生人物使用第一幕`Puppet`现实／中年老周和小禾、第二幕`Villager`；不得逐镜重设外观，也不声称已完成原PNG精细拆层。
3. 统一皮影、剪纸、宣纸舞台及[STYLE_GUIDE](../red-paper-reborn/STYLE_GUIDE.md)。正式字幕继续使用`Dialogue formal`：44px宋体、左右120px、底部78px、160px宣纸承托，按原稿窗口分句。
4. 动画由帧、fps和缓动控制，SVG定义使用唯一ID。复用`ShadowStage`、`CameraLayer`、山脊、老屋和道具；历史资料与虚构家庭故事分层，不虚构统计、人物原话、现场音或收益图。
5. 独立幕从0秒计时，三幕全片起点为0／1200／2700帧，不在各镜重复添加偏移；转场包含在规定镜长内。
6. 当前仅字幕与原创程序环境音；真人老周、小禾和旁白录音及最终音乐混音仍待制作。声音窗口、来源和再生成方式见各幕交接与音频说明。
7. 完成新镜后保留首中末图并检查实际导出，再更新[24镜进度](分镜与制作进度.md)。不上传依赖、缓存、个人路径、凭证或无关桌面材料，不强推，不覆盖队友工作。
