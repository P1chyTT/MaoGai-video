## 可用于本片的事实

| 时间或事项 | 本片采用的简要事实 | 依据与用途 |
| --- | --- | --- |
| 过去的产业与代价 | 余村曾依靠石矿开采、水泥生产获得收入，也承受粉尘、水污染等环境代价 | S1、S4；镜01、02、04。只作产业背景，不为虚构家庭填入具体履历 |
| 2003—2005年 | 余村陆续关停矿山和水泥厂，探索转型；关停伴随就业和收入压力 | S2，并参照S1、S4；镜05、06。写为过程，不编统一关停日 |
| 2005年8月15日 | 时任浙江省委书记习近平在余村考察，肯定关停矿山、探索转型，并首次提出“绿水青山就是金山银山”理念 | S3、S5；镜09、10。关停和探索在先，考察与理念提出在后 |
| 持续治理与经营 | 余村开展生态修复、治水等工作，发展乡村旅游及农家乐、民宿，带动农产品销售 | S1、S2、S4；镜08、12—16。多阶段概括，不表现为瞬间变绿或立即致富 |
| 农产品 | 公开资料涉及笋干、茶叶等销售，以及余村大米等旅游商品 | S2、S6；镜15、18。包装为创作，不标无依据的认证、价格和订单数 |
| 2021年12月2日 | 余村入选首批联合国世界旅游组织“最佳旅游乡村” | S5；镜16。按当时机构名称呈现，不仿造奖状或奖牌 |
| 2022年7月及以后 | 余村启动全球合伙人计划，青年与新业态参与发展 | S3，参照S2；镜17、20仅作青年参与背景。小禾不是该真实计划成员 |
| 理论方向 | 推动绿色发展，促进人与自然和谐共生；坚持生态保护，倡导绿色低碳生产生活方式 | S7；镜07、11、19、22、23。属于公开理论依据，课程教材原文另待核对 |

各资料对关停起始、全部关停和经营探索的表述口径有所不同。本片采用S2明确的“2003—2005年陆续关停”，不压缩为同一天。S4记载个别农家乐早在2002年已作尝试，故片中的探索是过程概括，不宣称农家乐始于2005年考察后。

## 史实与创作的分界

| 内容 | 属性 | 画面与文案处理 |
| --- | --- | --- |
| 老周、小禾、爷孙关系、家庭记忆、对白 | 艺术虚构的综合人物与情节 | 在开场和片尾明确“人物及家庭故事为艺术虚构”；不嫁接真实村民姓名或人生履历 |
| 开场旧图、矿山回忆、集体讨论、劳动动作 | 绘制的历史场景或过程示意 | 旧图标“历史场景示意”；不称真实老照片，不仿制历史文件、投票票数或会议原貌 |
| 2005年考察与理念提出 | 真实历史信息 | 由独立旁白和资料卡承担；不安排虚构爷孙参与真实历史座谈，不制作领导人皮影形象、模仿配音或虚构现场对白 |
| 小禾的拍摄、剪辑、路线、出游提示、爷孙约定 | 课程创作情节 | 路线标“课程创作示意”；界面自绘，不显示虚构播放量、收入或“上传成功”来证明发展成效 |
| 经营与保护循环、延展山水长卷 | 教学概括与主题意象 | 循环线不表示金额或比例；镜22两侧场景标“主题示意，不指向具体项目” |
| 三种效益与现代化主题 | 基于公开资料的主题表达 | 不将自拟总结包装为教材引文、历史原话或统计结论 |

全片不使用集体收入、人均收入、游客量、减碳量等统计值；不混用“余村”与“大余村”的范围。片尾简列来源机构，完整链接保留在本文件与配套脚本。
