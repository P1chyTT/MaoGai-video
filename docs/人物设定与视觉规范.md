## 二、主题、故事与人物关系

片名《山河有约》，副标题“从绿水青山到金山银山”；课程主题“推进生态文明建设”。故事发生于浙江省湖州市安吉县天荒坪镇余村，当下返乡与历史回望交织。通过产业收入与污染的矛盾、关停后的生计压力、长期生态修复、适宜经营和青年参与，表现生态保护与经济发展相互促进、生态效益经济效益社会效益相统一。生态价值不能简化成旅游收入，山水不能直接变成金币。

小禾返乡完成课程视频，起初想拍热门。爷爷老周借绘制旧图讲述过去的收入、粉尘和转型焦虑；独立历史资料卡交代2005年考察与理念。爷孙沿溪观察修复、农家经营与农产品销售，小禾将“出圈”改为“走远”，记录普通劳动，设计课程中的步行路线与绿色出游提示，最终和爷爷共同拍摄旧今山脊对照。

| 关系 | 正式设定及表演边界 |
| --- | --- |
| 老周—小禾 | 爷爷与孙女；小禾对白称“爷爷”。两代人共同学习、合作，不是陌生导游与游客，也不把老人塑造成被青年教育的对象。 |
| 老周—村民 | 产业转型中的普通参与者之一；不包办全部治理工程，不掌握全部历史，不冒充真实人物或历史座谈见证人。 |
| 小禾—村民 | 返乡课程拍摄者与家乡劳动、经营者；拍摄前示意征得同意，尊重工作和日常生活。 |
| 村民之间 | 共同选择、治理、经营、管护的综合群像；没有新增有名有姓支线人物，不机械列队或统一挥手。 |
| 人物—历史 | 老周、小禾及家庭经历均为艺术化虚构；历史由旁白及资料卡承担。不得画领导人皮影、模仿本人声音，或让虚构爷孙进入真实历史座谈会。 |

## 三、人物基本信息与模板识别

### 小禾

- **身份／定位：**艺术化虚构的返乡女大学生，老周的孙女，为完成课程视频而拍摄家乡。脚本没有给出确切年龄，不自行指定年龄或新增职业。
- **性格／变化：**活泼、独立，关心产业、收入与传播；从快速滑屏、追求热度，转向慢观察、认真落笔、记录劳动与参与行动。
- **外观锁定：**原图向左侧脸；黑色高马尾、红色发饰、绿色传统衣装、棕色双肩背包、黑色相机，深色鞋。保留额鼻唇下颌轮廓、马尾走向与发饰位置。
- **纹样／结构：**乳米色植物、鸟、山水与村落纹样，暖色皮革肌理；肩、肘、膝、踝等可见金色铆钉。现有相机在胸腹前由双手持握。
- **故事功能：**以追问推动叙事，以修改拍摄方案把理解转为青年参与，不写成真实“全球合伙人”计划成员，不编造爆款成果。
- **素材：**[xiaohe.png](../red-paper-reborn/public/assets/characters/xiaohe.png)。完整人物设计图，尚未拆分。

### 老周

- **身份／定位：**艺术化虚构的综合人物；现实约六十多岁，曾参与矿山或相关工业生产。小禾的爷爷，不对应任一真实村民的完整履历。
- **性格／变化：**朴实、沉稳、关心后代；亲历收入与污染的矛盾、关停的焦虑，认可探索新路，支持孙女接力。语气温和，不训诫或作全知讲解。
- **外观锁定：**原图向右侧脸；灰白头发与胡须、棕色帽子、棕绿相结合的传统衣装、深棕鞋。现有一手扶弯柄拐杖，一手掌心展开；保留帽形、鼻唇下颌及胡须识别。
- **纹样／结构：**山水、村屋、叶纹装饰与皮革肌理，肩肘膝踝等金色铆钉清晰。不得用旧片奶奶素材替代。
- **时间版本：**该 PNG 为老年现实外观参考；01、02、05、06回忆段、08需中年版本，尚未提供。正式制作时从同一识别标准制作中年衍生版本，保留侧脸与帽形，不把白发老年模板直接当年轻工人。
- **素材：**[laozhou.png](../red-paper-reborn/public/assets/characters/laozhou.png)。完整人物设计图，尚未拆分。

### 余村村民群像

- **身份／定位：**无实名的综合群像，表现共同决策、生态治理、绿色经营和日常生活；是三套基础外形参考，不是一个独立角色。
- **现有三人：**左侧男性戴草帽、青绿衣、捧植物筐、朝左；中间女性戴红头巾、红棕衣、端物产托盘、朝右；右侧男性戴深色帽、深绿棕衣、持长柄铲／锹、朝右。保留人物相对位置、比例与各自完整轮廓。
- **统一识别：**不同衣色和帽饰，均为成人侧面造型、暖色皮革、植物与山水民俗纹样、金色铆钉。群像不复制小禾或老周来冒充不同村民。
- **复用方式：**后续以帽子、围裙、工具、背包等衍生配置表现旧产业劳动者、清理者、种植者、巡护者、接待者、经营者及游客；职业变化不能据此宣称是真实某户的经历。
- **限制：**原图只有三位成人；没有独立儿童，也没有全部职业动作。16镜儿童随家人在安全步道行走的素材待补；不得把现有成人缩小称为儿童。
- **素材：**[yucun_villagers_group.png](../red-paper-reborn/public/assets/characters/yucun_villagers_group.png)。保留整张群像设计图；没有拆出三位独立人物。

## 五、人物视觉规范

| 项目 | 统一执行规则 |

| 头身比例 | 保留每张模板内人物原有成人比例、头部与躯干及肢体长度关系；视觉为约六头身的成人倾向，仅作观察而非精确测量。帽子、马尾不并入颅顶至下颌的头高。当前没有净角色轮廓与统一骨点测量，不另造精确比例数值；分层时以原图逐部位对位锁定比例，禁止依近似数字重画。 |

### 场景配色与字幕约束

正式 Word 第七部分的色票用于新场景及新道具：森林绿 `#315D45`、山水青 `#6A9B8B`、天空蓝 `#A8C9C2`、大地棕 `#8A6849`、宣纸米黄 `#F2E5CB`、传统金色 `#C79540`。初始化工程另有文字轮廓深绿 `#263D30`。所有模板仍保留原始像素与颜色，不强制套色。

正式镜头按 Word 保留左右各120px、上下各70px安全边距及底部约160px字幕区；宋体／思源宋体40—44px、两行以内，每行尽量不超过22个汉字。不能把完整设计图的姓名牌当作对白字幕。已有技术预览的36px字幕、90px字幕带属于初始化实际值，正式镜头仍须按 Word 调整；本次没有修改预览代码。

## 七、素材引用与动画制作约束

### 唯一原始参考入口

```text
red-paper-reborn/public/assets/characters/xiaohe.png
red-paper-reborn/public/assets/characters/laozhou.png
red-paper-reborn/public/assets/characters/yucun_villagers_group.png
```

所有后续镜头开工前必须先检查上述素材、本文和对应 Word 镜头。**禁止为了单独一个镜头重新设计小禾或老周。** 原始参考文件保持不可覆盖；不去背景、不裁身体或关节、不拼图、不重绘、不风格迁移、不改变颜色、发型、服饰、面部轮廓和画内相对比例。群像保持完整群像属性。

工程的 public 根目录是 `red-paper-reborn/public/`，因此将来用 Remotion `staticFile()` 引用参考图时，相对路径为 `assets/characters/xiaohe.png` 等，不能再写 `public/` 前缀。这些是参考展示路径，不代表可将带背景设计图直接当成透明人物表演。不要在仓库根部另建重复人物库。

既有 `characters/xiaohe/`、`characters/laozhou/`、`characters/crowd/` 目前只保留说明，未来可放审定的衍生图层；三张原始 PNG 只保存在上面的规范位置。新增衍生件另命名、记录所源模板和修改说明，保持原件可追溯。

### 当前可用程度

**当前版本为人物视觉设定模板，正式骨骼动画使用前可能需要进一步分层。** 三张均为 RGB、不含 alpha；背景、边饰、姓名牌、皮革纹样和关节铆钉已合在一张图里。可用于角色审美、服饰与比例参照、团队参考板；尚不能直接用于透明人物叠景、独立眨眼／表情、手臂关节旋转或真实镂空透光。

本次没有制作头、躯干、上臂、前臂、手、腿等独立层，没有建立骨点、补齐遮挡纹样、绑定道具或制作表情替换。后续如需要拆层，须在单独衍生文件内保留原纹理与轮廓并逐部位对照；不能拉伸完整海报模拟弯臂，不能把姓名牌、背景一同移动当作人物动作。

人物在后续获准的镜头制作中可以改变位置、朝向、姿态、手臂动作、脚本需要的手持道具及原风格内的表情；基础外观仍以上述原件为标准。保持表演节制：平静、疑问、专注、微笑四类替换为主，不做夸张口型。手机、旧图、杯等随接触手绑定，避免漂移。

### 后续工程执行标准

沿用 React、TypeScript、Remotion；帧号、固定插值和关键帧驱动，随机使用固定种子，不用运行时随机、计时器、不可复现 CSS 动画或付费文生视频接口。以 SVG 分组、遮罩、关节旋转与分层视差实现动作，单镜推进通常3%—8%，具体以 Word 为准。

每镜先验首／中／末帧，再检查连续手势、视线、道具接触、阴影方向和转场。字幕避让人物与道具；日期及历史事实置资料层；对白严格采用 Word 第六部分，老周、小禾、旁白分轨。素材引用规范不等于已经完成这些动画或声音验收。
